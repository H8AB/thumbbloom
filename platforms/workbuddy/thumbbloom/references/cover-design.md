# Cover design decisions

## Copy

- Main text should communicate a single benefit, tension, or useful question. Prefer concrete nouns and verbs over generic hype.
- Keep labels such as series name, episode number, or content type secondary.
- When a title is long, edit it for the cover while preserving its meaning. Leave exact required wording intact.
- For an article, a quieter editorial treatment may fit better than a video thumbnail. For an educational video, a single diagram or strong contrast can carry the message.

## Composition

- Check at realistic feed size. If the focal idea disappears, enlarge it or remove competing details.
- Use a limited palette and type scale. Avoid tiny text that only reads in the editor.
- Plan crops for each target ratio; do not stretch a finished 16:9 composition into 9:16.
- Reserve margins for uncertain platform overlays and ask for a screenshot if exact UI placement matters.
- Make decorative elements support the idea, not imply evidence the content lacks.

## Quality review

Confirm: headline matches the content; all Chinese/Latin characters and numbers are correct; contrast is adequate; no essential content is clipped; imagery and marks are licensed or original; each export opens and has the requested dimensions. State which checks could not be performed in the current host.
